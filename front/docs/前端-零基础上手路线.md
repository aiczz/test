## 1. Flutter 这个选择：我支持，说明理由

我之前推荐 Capacitor（Vue + Web），理由是"零基础不用学新语言"。**但你有 C/Python 基础，"不用学新语言"这个优势就大幅缩水了** —— 因为 Dart 对你的熟悉度其实比 JS 更高。

### 1.1 公平对比

| | **Flutter** | Capacitor（Vue + Web） |
|---|---|---|
| 语言 | Dart —— **静态类型、C 系语法、有类** | JS —— 动态类型，一堆坑 |
| 从 C/Python 过来 | **很熟**：`int x = 1;`、`class`、`for`、`Future` | 要重新适应动态类型、`this`、闭包陷阱 |
| 要学几样东西 | **2 样**：Dart + Flutter Widget | **5 样**：HTML + CSS + JS + Vue + Vant |
| **CSS 布局** | **完全不用学** ⭐ | 必学（flex/grid/盒模型，新手时间黑洞） |
| 调试 | 模拟器/真机 + 热重载，没有浏览器 DevTools | Chrome DevTools，最舒服 |
| **打包上手机** | **`flutter run` 直接装，几乎零成本** ⭐ | 要配 Capacitor + Gradle，是最大风险点 |
| 出网页（保底） | `flutter build web` ✅ | `npm run build` ✅ |
| 环境搭建 | Flutter SDK + Android Studio | Node + Android Studio |

### 1.2 三个对你有利的点

1. **不用学 CSS。** 这是最大的隐藏收益。新手在 CSS 布局上烧掉一两天太常见 —— Flutter 用 `Row` / `Column` / `Container` 替代，行为更可预测。
2. **打包不用单独闯关。** `flutter run` 会把 App 直接装到连接的手机上 —— **第 1 天你手机上就有 App 了**。Capacitor 那条路的"打包可能失败"风险在这里基本不存在。
3. **一套语言到底。** 不用在 HTML/CSS/JS/框架/组件库之间来回切换心智。

### 1.3 ⚠️ 但有三个真实代价，必须知道

| 代价 | 说明 | 应对 |
|---|---|---|
| **布局约束模型** | "约束向下传，尺寸向上传" —— **Flutter 新手的头号门槛**，`RenderFlex overflowed` 会让你抓狂 | 第 3.2 节专门讲；遇到就贴给我 |
| **没有浏览器 DevTools** | 调试靠热重载 + 真机 + Dart 报错栈 | 热重载其实很好用；报错栈比 JS 清楚 |
| **UI 更啰嗦** | 同样的卡片，Flutter 要写 30 行，Vue 可能 10 行 | 但**不需要调样式**，总体不一定更慢 |

> **结论：换 Flutter 是合理的，40 小时的账也还成立。** 下面按 Flutter 重排。

## 3. Dart 速通（对照 C/Python，一个下午）

### 3.1 语言差异表

| C / Python | Dart |
|---|---|
| `int x = 1;` / `x = 1` | `int x = 1;` / `var x = 1;` / `final x = 1;` |
| `def f(a):` | `String f(int a) { ... }` ← **要写返回类型** |
| `list` / `List<int>` | `List<int>`、`[1,2,3]` |
| `dict` | `Map<String, dynamic>`、`{'k': v}` |
| `print(f"{n} 道")` | `print('$n 道')` ← **`$` 插值，不是 `{}`** |
| `lambda x: x*2` | `(x) => x * 2` |
| `class X:` | `class X { X(this.a); }` |
| `None` | `null` —— **有 null safety，可空要写 `String?`** |
| `async/await` | 一样，返回 `Future<T>` |
| `import x` | `import 'package:http/http.dart' as http;` |
| `for x in arr:` | `for (final x in arr)` |

**数组方法（天天用，和 Python 几乎一样）**
```dart
list.map((d) => d.name).toList()
list.where((d) => d.price < 10).toList()
list.firstWhere((d) => d.id == 1042)
list.fold(0.0, (s, d) => s + d.price)
```

### 3.2 ⚠️ 必须理解的三件事（和 C/Python 最不一样的地方）

**① Widget 树 —— 界面是嵌套的组件，不是 HTML**

```dart
// 一个卡片 = 一层层嵌套的 Widget
Card(
  child: Padding(
    padding: const EdgeInsets.all(16),
    child: Column(
      children: [
        Text('番茄炒蛋'),
        Text('¥12.5'),
      ],
    ),
  ),
)
```
看着啰嗦，但**不需要写 CSS** —— 布局和样式都在这棵树里。

**② setState —— 改数据后要喊一声**

```dart
class _PlanPageState extends State<PlanPage> {
  int weight = 50;

  void onSliderChange(double v) {
    setState(() => weight = v.toInt());   // 不调 setState，界面不会变
  }
}
```
**忘写 `setState` = 界面不动**，这是最常见的困惑。

**③ ⚠️ 布局约束模型 —— 头号门槛**

> **约束向下传（父给子最大/最小尺寸），尺寸向上传（子告诉父我要多大），位置由父决定。**

两个必踩的错：

```dart
// ❌ 报错 "RenderFlex overflowed by 37 pixels"
Row(children: [Text(很长的文字), Icon(Icons.add)])

// ✅ 用 Expanded 让它占剩余空间
Row(children: [Expanded(child: Text(很长的文字)), Icon(Icons.add)])
```

```dart
// ❌ 报错 "unbounded height"
Column(children: [ListView(...)])

// ✅ ListView 需要有限高度
Column(children: [Expanded(child: ListView(...))])
```

**记住这两条，能省下你半天。** 遇到别的报错就贴给我。

你只有 8 天，**设计别超过 1 小时**。别做高保真设计稿。

## 7. 接口契约：后端还没开始，更要现在定

### 7.1 今天就去找他定这份 JSON

```jsonc
// GET /api/plan?user_id=u01&week=2026-W38
{
  "week": "2026-W38",
  "budget": 300,
  "total_cost": 287.5,
  "days": [
    { "date": "2026-09-15", "weekday": "周一",
      "meals": [
        { "slot": "dinner",
          "dishes": [
            { "id": 1042, "name": "番茄炒蛋", "servings": 2,
              "reason": "换掉这道后钠仍达标，且能用掉周三到期的菠菜",
              "tags": ["家常", "快手"] }
          ] }
      ] }
  ],
  "shopping_list": [
    { "category": "蔬菜",
      "items": [
        { "name": "番茄", "amount": 500, "unit": "g",
          "price": 5.2, "price_source": "local" }
      ] }
  ]

```

**字段定了就别改。** 要改必须同时通知他。

### 7.2 假数据先行

把样例存成 `assets/mock/plan.json`，在 `pubspec.yaml` 里声明：

```yaml
flutter:
  assets:
    - assets/mock/
```

统一封装请求：

```dart
// lib/services/api.dart
import 'dart:convert';
import 'package:flutter/services.dart' show rootBundle;
import 'package:http/http.dart' as http;

const useMock = true;                              // 后端好了改 false
const base = 'http://10.0.2.2:8000';               // Android 模拟器访问本机

Future<Map<String, dynamic>> getPlan(String userId, String week) async {
  if (useMock) {
    final raw = await rootBundle.loadString('assets/mock/plan.json');
    return jsonDecode(raw);
  }
  final res = await http.get(Uri.parse('$base/api/plan?user_id=$userId&week=$week'));
  if (res.statusCode != 200) throw Exception('接口失败: ${res.statusCode}');
  return jsonDecode(utf8.decode(res.bodyBytes));   // ⚠️ 必须 utf8 解码，否则中文乱码
}
```

> ⚠️ **`utf8.decode(res.bodyBytes)` 这行很关键** —— 直接 `res.body` 中文会乱码，这是 Dart 最常见的坑之一。

> 💡 **真机连后端**：`10.0.2.2` 只对模拟器有效。真机要用**电脑的局域网 IP**（`ipconfig` 查，如 `192.168.1.5:8000`），且手机和电脑连同一 WiFi。

### 7.3 最后的保底

如果后端第 4 周还没出接口 —— 让他**跑一次算法导出 `plan.json`**，你替换 assets 里的文件。演示照样能跑。

## 8. 保底方案：`flutter build web`

Flutter 能编译成网页，所以你有和 Capacitor 一样的退路：

```bash
flutter build web
cd build/web
python -m http.server 8000        # 或 npx serve
```

手机连同一 WiFi，浏览器打开 `http://电脑IP:8000` → 添加到主屏幕 → 全屏演示。

**注意**：Flutter Web 首屏加载比原生 Web 慢（要下几百 KB 的 wasm/js），中文字体首次可能闪烁。**能用 apk 就用 apk，这只是兜底。**

## 10. Flutter 特有的坑（提前知道就不慌）

| 坑 | 表现 | 解决 |
|---|---|---|
| **`RenderFlex overflowed by X pixels`** | 黄黑条纹警告 | 用 `Expanded` / `Flexible` 包住超出的子组件 |
| **`unbounded height`** | 布局报错 | 给 `ListView` 套 `Expanded`，或指定高度 |
| **界面不刷新** | 改了数据没反应 | **忘了 `setState`** |
| `flutter doctor` 报红叉 | —— | 按提示一个个解决；Android licenses 一定要接受 |
| 手机连不上 | `flutter devices` 空 | 开 USB 调试；装手机厂商 USB 驱动；换根数据线 |
| 中文乱码 | 接口返回乱码 | 用 `utf8.decode(res.bodyBytes)` |
| 热重载没生效 | 改了没变 | 热重载 `r` 不重置状态，试热重启 `R` |
| 模拟器太慢 | 卡 | **直接用真机**，别折腾模拟器 |
| 真机连不上后端 | 请求超时 | `10.0.2.2` 只对模拟器；真机用电脑局域网 IP |
| 一个样式调一小时 | 时间黑洞 | **设 30 分钟上限**，超时换个简单实现 |
