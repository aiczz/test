## 二、遇到的 5 个坑（按发生顺序）

### 坑 1：`storage.googleapis.com` 不通 → Flutter 下载不了

**症状**
```
[!] 访问 Google 存储失败
```
下载 SDK 时必定失败。

**原因**：`storage.googleapis.com` 在国内被墙。（实测 DNS 解析到 `74.125.x.x` 等美国 IP。）

**解法**：**脚本已内置自动探测**，会依次尝试：

| 顺序 | 源 | 地址 |
|---|---|---|
| 1 | 官方 | `storage.googleapis.com` |
| 2 | **Flutter 社区 CFUG** | `storage.flutter-io.cn` |
| 3 | 清华 TUNA | `mirrors.tuna.tsinghua.edu.cn/flutter` |
| 4 | 上海交大 SJTU | `mirror.sjtu.edu.cn` |

选中哪个就自动把这两个变量**永久写入用户环境**：

```
FLUTTER_STORAGE_BASE_URL  → Flutter SDK 与引擎产物
PUB_HOSTED_URL            → Dart 包（flutter pub get）
```

> ⚠️ **这两个变量必须永久设置。** 只配下载、不配 pub 的话，以后 `flutter pub add http` 照样卡死。
> 参考：[Flutter 官方文档 · 在中国网络环境下使用 Flutter](https://docs.flutter.cn/community/china/)

### 坑 2：解压失败 —— Windows 260 字符路径上限

**症状**
```
使用"2"个参数调用"ExtractToDirectory"时发生异常:
"未能找到路径"...\flutter_extract_1798714463\flutter\engine\src\flutter\testing\
ios_scenario_app\ios\Scenarios\ScenariosUITests\golden_platform_view_clip_path_
with_transform_multiple_clips_impeller_iPhone SE (3rd generation)_26.2.simulator.png"的一部分。"
```

**原因**：Windows 传统路径上限 **260 字符**。Flutter 压缩包里含引擎的 iOS 测试资源，文件名极长；而 `C:\Users\<你>\AppData\Local\Temp\` 这个前缀本身就占 62 字符，加起来 **261** —— 差 1 个字符就炸。

**解法**：**解压临时目录必须选在靠近盘符根的位置。**

```
✗ C:\Users\POLARIS\AppData\Local\Temp\flutter_extract_xxx   → 261 字符，失败
✓ D:\_fx                                                    → 205 字符，通过
```

脚本已改为 `D:\_fx`，并加了 **`tar` 回退**（Windows 自带 `tar.exe` 原生支持超长路径）。

> 💡 **通用经验**：以后看到「未能找到路径的一部分」或「路径太长」，基本都是这个原因。
> **任何解压/构建操作，临时目录都选在盘符根附近**（`D:\_fx` 好，深层 Temp 差）。

### 坑 3：UAC 弹窗找不到，窗口"点不动"

**症状**：winget 装 Android Studio 时输出 `安装程序将请求以管理员身份运行。期待提示。`，然后**没有任何弹窗**，且**鼠标点哪都没反应**。

**原因**：UAC 提示窗口**确实弹出来了，但没到前台**（被其他窗口挡住 / 在另一块屏幕上）。窗口"点不动"正是最明确的信号 —— 有模态对话框在独占输入。

**诊断方法**（在另一个 PowerShell 里跑）：
```powershell
Get-Process -Name consent    # consent.exe 在跑 = UAC 窗口确实存在
```

**解法**：
1. **按 `Alt` 连按 `Tab`**，找标题「用户账户控制」的窗口
2. 看**任务栏**有没有闪烁的盾牌图标
3. `Win + D` 显示桌面
4. 多显示器的话检查另一块屏幕
5. **`Ctrl+Alt+Del` 永远管用** —— 它由系统直接处理，不受冻结窗口影响。从那里进任务管理器结束卡住的进程

> 💡 **记这条**：以后遇到「鼠标点哪都没反应」，先想「是不是有弹窗藏在后面」。

### 坑 4：Android Studio 报 `Unable to access Android SDK add-on list`

**症状**：首次启动弹窗
```
Android Studio First Run
Unable to access Android SDK add-on list
[Setup Proxy]  [Cancel]
```

**原因**：Android Studio 被设成「**自动探测代理**」（`USE_PROXY_PAC = true`），但系统里**没有可用的 PAC 也没有开代理**，于是连不上。

实测配置：
```
Android Studio proxy.settings.xml :  USE_PROXY_PAC = true
系统 ProxyEnable                  :  0（关闭）
系统 ProxyServer                  :  127.0.0.1:7897   ← Clash 类工具的默认端口，但工具没开
PAC 地址                          :  (空)
```

**解法**：**点 `Setup Proxy`（不是 Cancel！）→ 选 `No proxy` → OK**

**为什么 `No proxy` 是对的**：实测 DNS
```
dl.google.com           → 220.181.174.33        国内 CDN（北京电信）
storage.googleapis.com  → 74.125.x.x            美国 IP（被墙）
```
**Android SDK 全部从 `dl.google.com` 下载，走的是国内 CDN，直连即可，不需要代理。**

> 如果选了 `No proxy` 仍不行，说明代理工具开着但没设系统代理：
> `Setup Proxy` → `Manual proxy configuration` → HTTP → `127.0.0.1:7897` → `Check connection`

### 坑 5：`flutter doctor` 报 `cmdline-tools component is missing`（本次未致命）

**症状**：Android toolchain 出现警告。

**解法**（如果真遇到）：Android Studio → `Tools` → `SDK Manager` → 左侧 **`SDK Tools`** 标签 → 勾选
```
☑ Android SDK Command-line Tools (latest)
```
→ `Apply` → `OK`

> **本次实测**：没装 cmdline-tools，但 `android-sdk-license` 已接受，`flutter doctor` **依然是全绿**。所以这一项可能不必要 —— 遇到了再补。

## 三、正确的操作顺序（推荐）

```
① 跑 setup-flutter.ps1
     → 自动选镜像、下载 Flutter、配 PATH
     → 自动 winget 装 Android Studio（会弹 UAC，注意找那个窗口）

② 打开 Android Studio，走首次启动向导
     → Import Settings: Do not import settings
     → Install Type:     Standard
     → License Agreement: 每一项都点 Accept
     → 等下载 3–5 GB（都从 dl.google.com 下，能下动）
     → 如果弹 "Unable to access Android SDK add-on list" → Setup Proxy → No proxy

③ 再跑一次 setup-flutter.ps1
     → 自动配 ANDROID_HOME、接受许可、跑 flutter doctor

④ flutter doctor 全绿 → 搞定
```
