> **环境**：Windows + Android 手机
> **技术栈**：Flutter + Dart

## 开始前：准备清单

| 项 | 说明 |
|---|---|
| Windows 电脑 | 磁盘至少留 **15 GB**（Android Studio + Flutter 很占地方） |

# D1（5 小时）：环境 + App 跑上手机

## 时段 1（0:00–0:30）先把两个大文件挂上

**同时开始下载，别一个个来**（下载是瓶颈）：

1. **Flutter SDK** → https://docs.flutter.dev/get-started/install/windows
   下载 **stable 版的 zip**（约 700 MB），先放着别解压
2. **Android Studio** → https://developer.android.com/studio
   下载安装包（约 1 GB）

> 💡 如果下载很慢，检查网络。这一步是整天的瓶颈。

---

## 时段 2（0:30–2:00）装 Android Studio

1. 安装时**勾选 Android Virtual Device 可以不勾**（我们用真机，省磁盘）
2. 首次启动会引导下载 **SDK** —— 让它下完，这一步很慢
3. 装完后确认 SDK 路径，一般在：
   `C:\Users\你的用户名\AppData\Local\Android\Sdk`

> ⚠️ **JDK**：新版 Android Studio 自带 JBR（JetBrains Runtime），一般不用单独装。

---

## 时段 3（2:00–2:45）装 Flutter SDK

1. 把下载的 zip 解压到一个**没有空格、没有中文的路径**，例如：
   ```
   C:\src\flutter
   ```
   ⚠️ **不要放在 `C:\Program Files\`**（有空格，会出问题）
2. 把 `C:\src\flutter\bin` 加进 **PATH**：
   - 开始菜单搜「环境变量」→ 编辑系统环境变量 → 环境变量
   - 在「用户变量」里找到 `Path` → 编辑 → 新建 → 填 `C:\src\flutter\bin`
   - **确定 → 确定 → 确定**（三层都要点）
3. **关掉所有终端，重新打开一个**，验证：
   ```bash
   flutter --version
   ```
   > 第一次运行会自动下载 Dart SDK，要等几分钟，别以为卡死了。

## 时段 4（2:45–4:00）flutter doctor 逐项修到全绿

```bash
flutter doctor
```

它会列出一堆项目，**有 ✗ 或 ! 的都要解决**。最常见的两个：

**① Android toolchain — 未接受许可**
```bash

```
一路按 `y` 回车。**这步不做，最后打不了包。**

**② Android SDK cmdline-tools missing**
- 打开 Android Studio → 右上角齿轮/SDK Manager → SDK Tools 标签页
- 勾选 **Android SDK Command-line Tools (latest)** → Apply

**循环执行 `flutter doctor` 直到全部 ✓**，再往下走。

> ⚠️ **环境不干净，后面每一步都会踩坑。** 这 75 分钟值得花。实在修不好就把 `flutter doctor` 的完整输出贴给我。

## 时段 5（4:00–4:45）建项目 + 跑上手机

**① 手机连电脑**，允许 USB 调试授权弹窗

**② 确认手机被识别**
```bash

```
> 如果列表是空的：换根数据线、装手机厂商 USB 驱动、重新插拔。

**③ 建项目**
```bash

```

> ✅ **手机上出现「mealmind」图标，点开能看到计数器页面** → D1 成功！

**⑤ 试试热重载**
在终端里按 `r` → 界面立刻刷新，但状态保留。按 `R` → 完全重启。
**改代码 → 按 `r` → 立刻看到变化**，这是 Flutter 开发的主要节奏。

# D2（5 小时）：Dart 速通 + 预设家庭页

## 时段 1（0:00–1:00）Dart 差异速通

**边用边查，不要通读教程。** 对照你会的 C/Python：

| C / Python | Dart |
|---|---|
| `int x = 1;` / `x = 1` | `int x = 1;` / `var x = 1;` / `final x = 1;` |
| `def f(a):` | `String f(int a) { ... }` ← 要写返回类型 |
| `dict` | `Map<String, dynamic>`、`{'k': v}` |
| `print(f"{n} 道")` | `print('$n 道')` ← **`$` 插值** |
| `class X:` | `class X { X(this.a); }` |
| `None` | `null` —— 可空要写 `String?` |
| `for x in arr:` | `for (final x in arr)` |

```dart
// 数组方法，和 Python 几乎一样
list.map((d) => d.name).toList()
list.where((d) => d.price < 10).toList()
```

**两个必须理解的新概念：**

**① Widget 树** —— 界面是嵌套的组件，不是 HTML
```dart
Card(child: Padding(padding: const EdgeInsets.all(16), child: Text('番茄炒蛋')))
```

**② setState** —— 改数据后要喊一声，否则界面不动
```dart
setState(() => weight = v.toInt());
```

## 时段 4（2:15–4:30）预设家庭页（完整代码，直接抄）

**`lib/pages/family_select.dart`**（整个文件）

```dart
import 'package:flutter/material.dart';
import '../theme.dart';

/// 预设家庭：先写死，将来可以换成从后端读
class Family {
  final String id;
  final String name;
  final int people;
  final Color color;
  final List<String> meta;

  const Family(this.id, this.name, this.people, this.color, this.meta);
}

const families = [
  Family('f1', '三口之家', 3, accent,
      ['周预算 300 元', '妈妈高血压（限钠）', '孩子不吃辣', '只有一口炒锅']),
  Family('f2', '独居青年', 1, Color(0xFF2E5AA8),
      ['周预算 150 元', '每天加班', '爱吃辣', '微波炉 + 电饭煲']),
  Family('f3', '老年家庭', 2, muted,
      ['周预算 250 元', '糖尿病 + 高血脂', '口味清淡', '全厨具']),
];

class FamilySelectPage extends StatelessWidget {
  const FamilySelectPage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: SafeArea(
        child: ListView(
          padding: const EdgeInsets.all(16),
          children: [
            const Text('今天吃什么',
                style: TextStyle(
                    fontSize: 26, fontWeight: FontWeight.w600, color: ink)),
            const SizedBox(height: 4),
            const Text('选一个家庭档案，直接看本周菜单',
                style: TextStyle(fontSize: 14, color: muted)),
            const SizedBox(height: 20),
            for (final f in families)
              Padding(
                padding: const EdgeInsets.only(bottom: 12),
                child: _FamilyCard(family: f),
              ),
          ],
        ),
      ),
    );
  }
}

class _FamilyCard extends StatelessWidget {
  final Family family;

  const _FamilyCard({required this.family});

  @override
  Widget build(BuildContext context) {
    return InkWell(
      borderRadius: BorderRadius.circular(6),
      onTap: () => Navigator.pushNamed(context, '/plan'),
      child: Container(
        padding: const EdgeInsets.all(16),
        decoration: BoxDecoration(
          color: Colors.white,
          border: Border.all(color: rule),
          borderRadius: BorderRadius.circular(6),
        ),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // 标题行：名字 + 人数标签
            Row(
              mainAxisAlignment: MainAxisAlignment.spaceBetween,
              children: [
                Text(family.name,
                    style: const TextStyle(
                        fontSize: 17,
                        fontWeight: FontWeight.w600,
                        color: ink)),
                Container(
                  padding:
                      const EdgeInsets.symmetric(horizontal: 8, vertical: 3),
                  decoration: BoxDecoration(
                    color: family.color.withOpacity(0.12),
                    borderRadius: BorderRadius.circular(3),
                  ),
                  child: Text('${family.people} 人',
                      style: TextStyle(fontSize: 12, color: family.color)),
                ),
              ],
            ),
            const SizedBox(height: 10),
            // 约束列表
            for (final m in family.meta)
              Padding(
                padding: const EdgeInsets.only(bottom: 3),
                child: Row(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    const Text('—  ',
                        style: TextStyle(
                            fontSize: 13, color: Color(0xFFBBBBBB))),
                    Expanded(
                      child: Text(m,
                          style:
                              const TextStyle(fontSize: 13, color: muted)),
                    ),
                  ],
                ),
              ),
          ],
        ),
      ),
    );
  }
}
```

**⚠️ 注意这几处（都是新手会卡的点）：**
- `Expanded` 包住 `Text` —— 不加的话长文字会报 `RenderFlex overflowed`
- `withOpacity(0.12)` —— 做半透明底色
- `'${family.people} 人'` —— Dart 字符串插值
- `for (final f in families)` 直接写在 `children` 里 —— Dart 集合的 for 语法，非常好用

# 保底方案：`flutter build web`

万一 apk 出不来、或者演示时手机不方便，Flutter 能编译成网页：

```bash
flutter build web
cd build/web
python -m http.server 8000
```

手机连同一 WiFi，浏览器打开 `http://电脑IP:8000`（电脑 IP 用 `ipconfig` 查）→ 添加到主屏幕。

**这是兜底，不是主力。** apk 能用就用 apk。

# 常用命令速查

```bash
flutter doctor                  # 检查环境
flutter doctor --android-licenses   # 接受 Android 许可
flutter devices                 # 列出连接的设备
flutter run                     # 编译并装到手机（开发用）
r                               # （运行中）热重载
R                               # （运行中）热重启
q                               # （运行中）退出
flutter pub add 包名            # 装包
flutter build apk --release     # 出正式 apk
flutter build web               # 出网页版
```

release apk 路径：`build\app\outputs\flutter-apk\app-release.apk`

# 卡住了怎么办

| 情况 | 做法 |
|---|---|
| `flutter doctor` 一直报红 | **把完整输出贴给我**，逐项解决，别自己瞎试 |
| `RenderFlex overflowed` | 用 `Expanded` 包住超出的子组件 |
| 界面改了没反应 | 检查是否忘了 `setState`；试热重启 `R` |
| 手机连不上 | 换数据线、装 USB 驱动、重开 USB 调试 |
| 报错看不懂 | **把完整报错贴给我**（不要只贴最后一行） |
| 一个样式调了一小时 | **设 30 分钟上限**，超时换个简单实现 |
| AI 给的代码看不懂 | **追问到懂为止** —— 否则下周你改不动它 |
| 完全没进度、很焦虑 | 回退到上一个 commit 重来，往往更快 |
