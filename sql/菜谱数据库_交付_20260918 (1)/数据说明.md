### ✅ 2. 常用食材都包含吗 —— 包含

抽查 30 个常见食材，**25 个在表里**：

```
✓ 番茄 鸡蛋 猪肉 牛肉 鸡肉 土豆 白菜 菠菜 黄瓜 洋葱 胡萝卜

```

### ⚠️ 3. 食材有 tag 吗 —— **这是最弱的一环**

```
有中医功效 tag :   215 / 11,080  =  1.9%
有适宜人群 tag : 1,564 / 11,080  = 14.1%
```

**为什么这么低**：中医图谱里的功效/人群关系主要挂在**菜肴**上，
而语料里药膳菜谱极少（150 万道菜里只有约 10 条带药膳标签），
所以图谱里只有 **432 道菜**有功效边。用菜肴搭桥推食材，天花板就在这里。

**但已有的部分是准的**：

```
羊肉 -> 暖胃补肾, 益精气, 补肾阳, 温经止痛
山药 -> 健脾固肾, 补益气血, 补元气, 止咳润肺
红枣 -> 养血补虚, 补脾益气, 补元气, 润心肺
猪肝 -> 益目, 补肝, 养血, 明目
银耳 -> 滋阴润肺, 安神, 补气血
```

**要提高只能人工补**（比如给引用 ≥100 次的 860 个常用食材逐个填功效标签）。
你决定做不做，我可以列出候选清单。

### ✅ 4. 菜品是否清楚由若干食材构成 —— 是

```
菜品总数                     200,000 道
至少一个用料匹配到食材表      190,861 道 (95.4%)
每道菜平均匹配到食材          3.6 个
```

### ✅ 5. 每道菜的三件套是否齐 —— 齐

```
缺原材料 string : 27 道 (0.014%)   ← 源语料本身就空
缺做法 string   : 0 道
有 tag 的菜     : 94,692 道 (47.3%)
```

### ✅ 6. 查一个食材能否推到菜品 —— 能

```sql
-- 番茄能做的菜
SELECT d.dish_name FROM dish_ingredients di
JOIN dishes d ON d.id = di.dish_id
WHERE di.ingredient_id = (SELECT id FROM ingredients WHERE name='番茄');
```

实测：

```
番茄 ->  8,207 道菜
鸡蛋 -> 41,434 道菜
土豆 ->  9,584 道菜
```

## 三、执行顺序（有依赖，不能乱）

```bash
# 1) 原始语料 -> MySQL（解析用料字符串）
python process.py

# 2) 食材名清洗（62 万 -> 1.5 万个中心词）
python clean_pipeline.py

# 3) 建食材主表（分类 + 营养素 + 中医文本属性）
python build_main_ingredient.py

# 4) 剔除残留的非食材名
python drop_junk.py

# 5) 从食材/菜品导出字典表（含 tags.csv）
python build_dict_tables.py

# 6) 菜肴搭桥推食材功效/人群
python rebuild_tcm_via_dish.py

# 7) 建菜品表（读 tags.csv 才有 tag_id）
python build_dishes.py 200000
```

**第 5 步必须在第 7 步之前**——`build_dishes.py` 要读 `tags.csv` 才能把标签名转成 `tag_id`。
**第 4 步必须在第 5 步之前**——`drop_junk` 会改变食材表行号，
而 `ingredient_effects` 用行号做外键。

## 四、数据库该建几张表

**旧库六张表建议全删**（`recipes` / `ingredients` / `recipe_ingredient_names` /
`recipe_ingredient_quantities` / `recipe_instructions` / `recipe_tags`）。

原因：旧的 `ingredients` 是**未清洗**的 62 万行，含「个茄子」「汤勺热油」这类垃圾；
而且旧库**没有分类、没有营养素、没有中医属性、没有标签字典**。

```sql
DROP TABLE IF EXISTS recipe_tags, recipe_instructions,
    recipe_ingredient_quantities, recipe_ingredient_names, ingredients, recipes;
SOURCE build/schema.sql;
-- 按上文顺序导入 build/*.csv
```
